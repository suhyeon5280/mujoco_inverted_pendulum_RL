# 역진자(InvertedPendulum) 강화학습 입문

카트를 좌우로 움직여 막대가 넘어지지 않게 세우는 정책을 PPO로 학습합니다.
`exp.py`의 `compute_reward()`에 있는 가중치를 바꿔 보면서 결과가 어떻게 달라지는지 확인하는 과제입니다.

## 1. 환경 구축

Python 3이 설치되어 있다면 아래 명령 하나로 끝납니다 (Python 3.11에서 확인).

```bash
pip install -r requirements.txt
```

## 2. 실행

### 학습 + 평가

```bash
python exp.py
```

- 학습이 끝나면 모델이 `models/ppo_<날짜_시간>.zip`으로 저장됩니다.
- 마지막 줄에 **평균 지속 스텝**(막대를 세운 스텝 수, 최대 1000)이 출력됩니다. 이 숫자로 성능을 판단합니다.

### 시각화

```bash
python watch.py <모델 이름>
# 예) python watch.py ppo_20261103_142530
```

모델 이름은 `exp.py`가 마지막에 출력해 줍니다 (`.zip`은 빼고 입력).
막대가 **0.2 rad(약 11.5°)** 이상 기울면 넘어진 것으로 보고 곧바로 처음 상태로 리셋됩니다.

## 3. 보상 함수 가중치

`exp.py`의 `compute_reward()` 맨 위에 있는 네 개의 가중치만 바꾸면 됩니다.

```
보상 = r_alive − (p_angle + p_pos + p_action)
```

| 가중치 | 종류 | 계산 | 의미 |
|---|---|---|---|
| `w_alive` | 보상 (+) | `w_alive × 1` (서 있는 동안 매 스텝) | 오래 버틸수록 이득 |
| `w_angle` | 감점 (−) | `w_angle × θ²` | 막대가 기울수록 손해 |
| `w_pos` | 감점 (−) | `w_pos × x²` | 카트가 중앙에서 멀어질수록 손해 |
| `w_action` | 감점 (−) | `w_action × a²` | 힘을 세게 쓸수록 손해 |

- `x`: 카트 위치, `θ`: 막대 각도(rad), `a`: 카트에 가하는 힘
- 가중치를 모두 0으로 두면 보상이 항상 0이라 아무것도 학습되지 않습니다.
